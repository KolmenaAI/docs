Knowledge in Kolmena is the library of documents, links, and text you provide so your agents (and Maya) can answer questions, follow instructions, and make decisions with real context. You manage everything from the **Knowledge** page, where you can upload files, paste text, add web links, organize folders, and choose exactly who gets access.

## What you can add to Knowledge

Kolmena accepts several kinds of resources so you can bring in the context your agents need:

| Type | What to use it for |
| --- | --- |
| **Files** | Documents, code files, images, audio, and video. Drag and drop or browse to upload. |
| **Text** | Paste freeform text directly when you do not have a file handy. |
| **Links** | Add up to 20 URLs at a time. Each page is fetched and saved as searchable Markdown. |

<Note>
  There is a per-file size limit. If a file is too large, split it into smaller files and upload again.
</Note>

## The Knowledge page and libraries

When you open **Knowledge** from the sidebar, you work inside a library scope. You can switch between libraries to manage content for different contexts:

- **Agent or Swarm Knowledge** — resources attached directly to a single agent or swarm.
- **Shared Knowledge** — a central library you can share with any of your agents and swarms.
- **Archive** — a holding area for documents you have removed from active use. You can restore archived items or delete them permanently.

Use the scope switcher on the Knowledge page to move between these libraries.

## Organize with folders

Keep your knowledge tidy by creating folders. You can name folders, move documents between them, and archive or delete items in bulk. Folders help agents find the right context faster, especially when your library grows.

## How agents get access

Nothing is granted by default. You control access per document or for your entire Shared Knowledge library:

- **Per document** — open a document’s access settings and choose which agents and swarms can use it.
- **Shared Knowledge** — grant access to all agents and swarms at once from the library settings.

<Warning>
  The "All agents" grant never includes Maya. If you want Maya to use a document, grant her access explicitly.
</Warning>

Agents and swarms with access can recall your knowledge during conversations, job runs, and task execution. You can see how much knowledge is being ingested and recalled from your [usage and logs](/account/usage-and-logs) page.

## Processing and status

After you upload or add a resource, Kolmena processes it automatically so agents can search and recall it. While processing, you may see statuses such as:

- **Queued** — waiting in the processing queue.
- **Processing** — the document is being prepared for search.
- **Ready** — the document is available to your agents.
- **Failed** — something went wrong (for example, the file is corrupted, too large, or contains no readable text). You can retry failed documents manually.
