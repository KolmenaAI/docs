Installing a listing from the Kolmena Marketplace adds a private copy of an agent or swarm to your workspace. You can start with a free trial when one is available, buy a one-time license, or subscribe monthly. This page covers how to install a listing, manage your rental, and leave a review.

## Install a listing

<Steps>
  <Step title="Find a listing">
    Browse the [Marketplace](/marketplace) and open a listing that interests you. Read the description, sales pitch, and screenshots to understand what it does.
  </Step>
  <Step title="Choose your plan">
    The install dialog shows the pricing model: free, one-time purchase, or subscription. If a free trial is available, you can start it immediately. If you already used the trial for this listing, the dialog warns you that installing now begins paid billing right away.
  </Step>
  <Step title="Confirm and install">
    Click the install button. A private copy is added to your agents or swarms. For agents, an API key is generated so you can call the agent from outside Kolmena. For swarms, a copy of the full team is created.
  </Step>
  <Step title="Save your API keys">
    After installation, the dialog shows your API keys once. Copy and save them immediately. You can regenerate keys later from the agent detail page if needed.
  </Step>
</Steps>

## What happens after installation

When you install a listing, Kolmena locks the identity, persona, examples, and skills of the original agent or swarm. You cannot edit those parts, but you can set your own plugin credentials so the agent connects to your accounts.

For subscriptions, you keep access until the current billing period ends if you cancel. One-time purchases are yours permanently. Free listings have no billing at all.

## Manage or cancel a rental

You control your rentals from the detail page of the copied agent or swarm:

- **Cancel subscription** - Open the agent or swarm and click **Manage subscription**. Canceling stops future billing and keeps access until the period ends. There are no refunds.
- **Resubscribe** - If a subscription expires, a **Resubscribe** button appears to restart it.
- **Pull updates** - When the creator releases an update, a **Pull update** button appears. Applying the update brings in the latest version while preserving your credentials.
- **Renew** - For expired rentals, you can renew to regain full access.

## Leave a review

After you have used a listing, you can rate and review it to help other users:

1. Open the listing page in the Marketplace.
2. Click **Leave a review**.
3. Select a star rating from 1 to 5.
4. Write a short review, up to 300 characters.
5. Click **Submit Review**.

You can edit or delete your review at any time from the same listing page.
