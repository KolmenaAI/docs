Skills are reusable capabilities that extend what your agents know how to do. They range from built-in utilities to custom logic you write yourself. You manage skills from the **Skills** page in the sidebar, and you can also control them per agent under **Configure > Skills**.

## What skills are

A skill is a bundle of code and configuration that gives an agent new abilities. Some examples include:

- Fetching and parsing web pages
- Interacting with external APIs
- Running custom business logic

Each skill has one live version. All users and agents get the live version automatically, so you never need to update a skill by hand. Kolmena publishes new versions of Kolmena skills and can roll a skill back to an earlier version. Your agents pick up the change within seconds.

Kolmena skills show a **Kolmena skill** label in the list and in the skill's detail window. You can turn a Kolmena skill on or off, but you cannot edit it.

## Browse and install skills

Open **Skills** from the sidebar. The page shows two tabs:

- **All** — every skill available to you, including built-in defaults and ones you have added.
- **Enabled** — only the skills currently turned on for your agents.

### Add a skill

Click **Add Skill** in the header to choose how to bring a skill into your library:

<Steps>
  <Step title="Add from the web">
    Paste a URL to a public skill repository (for example, from GitHub). Kolmena downloads and reviews the skill, then adds it to your library. If the skill needs additional setup, you will see a notice and can complete it before enabling it.
  </Step>
  <Step title="Upload a skill file">
    Select a skill file from your computer and upload it directly. This is useful for skills you have built locally or received from a teammate.
  </Step>
  <Step title="Write your own">
    Create a skill directly in the editor. Give it a name, description, and the code that defines what it does. Once saved, it appears in your library like any other skill.
  </Step>
</Steps>

### Skill names

You cannot create a skill with the same name as a Kolmena skill. If you try, Kolmena shows the error "A Kolmena skill already uses this name. Choose another name." This applies when you write, upload, or add a skill from the web.

You also cannot write a new skill with the same name as one of your existing skills. Kolmena shows "You already have a skill with this name. Edit that skill instead."

If Kolmena later publishes a skill with the same name as one of your skills, your agents use the Kolmena skill instead of yours.

## Enable and disable skills

Each skill row shows whether it is on for your agents:

- **Default** — built-in skills that are enabled automatically for all agents. You cannot turn these off globally, but you can disable them per agent from the agent's **Skills** tab.
- **Enabled for all agents** — skills you have turned on for every agent.
- **Enabled for some agents** — skills you have granted to specific agents only.

Use the switch on each row to toggle a skill on or off for all agents. To grant it to specific agents instead, click the access pill and choose the agents you want.

<Note>
  Skill changes apply to running agents within seconds. You do not need to restart your agents after you turn a skill on or off or change which agents can use it.
</Note>

## Edit a skill

You can edit skills you created yourself. Kolmena skills cannot be edited.

1. Open the skill's detail window and click **Edit**.
2. Update the description and instructions. The skill name cannot be changed.
3. Click **Save**.

Kolmena saves your changes as the skill's new live version. Your running agents reload the skill within seconds.

## Skill updates

You do not need to update skills. When Kolmena publishes a new version of a Kolmena skill, every agent that uses it switches to that version automatically. If Kolmena rolls a skill back, your agents switch back to the earlier version the same way.

## Remove a skill

To remove a skill you added yourself, open its detail modal and click **Delete**. The skill is removed from your account and from every agent that uses it. Built-in and default skills cannot be deleted.

<Warning>
  Deleting a skill is permanent. If you delete a skill that agents are actively using, they lose that capability within seconds.
</Warning>

## Manage per-agent skills

You can also manage skills for one agent at a time:

1. Open the agent and go to **Configure > Skills**.
2. Toggle skills on or off for that agent only.
3. Per-agent choices override the workspace default, so you can give one agent a unique set of capabilities.
