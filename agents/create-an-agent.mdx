Creating a custom agent in Kolmena takes just a few steps. You give it a name and instructions, and Maya helps build the rest.

## Build an agent in a chat with Maya

You can also create an agent without writing configs or prompts. Start a new chat with Maya, describe what you want, and answer a few clarifying questions in plain language. Maya generates a full persona from the conversation. Then open **Configure** to refine the result before you publish and restart.

## Use the agent builder

<Steps>
  <Step title="Open the agent builder">
    Go to the **Agents** page and click **New Agent**. A creation modal opens where you describe what you want.
  </Step>
  <Step title="Name your agent">
    Enter a name of at least 3 characters. You can also upload an avatar image (JPEG, PNG, GIF, or WebP).
  </Step>
  <Step title="Describe what it should do">
    In the **What Should It Do?** field, write at least 50 characters describing the agent's role, personality, and tasks. The more detail you provide, the better the agent will perform.

    <Tip>
      Click **Improve Prompt** to have Maya rewrite and expand your description into a richer system prompt.
    </Tip>
  </Step>
  <Step title="Choose memory isolation (optional)">
    Toggle **Private Memory** if you want this agent's memory to be isolated. Isolated memory means the agent does not share context with other agents or Maya.
  </Step>
  <Step title="Build with Maya">
    Click **Build With Maya**. Maya processes your description and creates the agent's system prompt and configuration.
  </Step>
</Steps>

## What happens next

After the build completes, your agent is ready. You can:

- **Chat with it immediately** from the success screen
- **Open its workspace** to configure channels, skills, knowledge, and more
- **Publish it** to make the configuration live

## Fine-tuning after creation

Once your agent exists, open it and go to **Configure** to adjust:

| Section | What to set |
| --- | --- |
| Basics | System instructions, temperature, voice model, available models, memory isolation |
| Channels | Telegram, Discord, X/Twitter connections |
| Integrations | MCP services and apps |
| Skills | Custom or imported capabilities |
| Examples | Sample conversations for training |

<Note>
  Kolmena uses a core planner that selects the best model for each step automatically. You can manage which models are available and set a voice model, but you do not pick a single static model for the entire agent.
</Note>

### Configure the persona, skills, and examples

Use the persona field to shape how the agent communicates, how direct it is, and when it should say it does not know. Temperature controls how consistent or creative its replies feel. Under **Examples**, add a real question and the answer you want back so the agent picks up the tone, structure, and level of detail.

### Manage models

To control which models an agent can use, open **Configure**, go to **Basics**, and click **Manage Models**. Models are grouped by type, such as small and large models, image interpretation, image generation, dashboard creation, and planner models. Turn models on or off to balance quality, speed, and cost. Changes apply only to the agent you are editing.

### Change the agent's voice

Kolmena assigns each new agent a default voice, which you hear in voice mode. To change it, open **Configure**, go to **Basics**, click **Manage** in the **Manage Models** section, and select **Voice**. Preview the current voice, then filter the library of more than 17,000 voices by language, accent, gender, and use case, and test any voice before selecting it. Publish and restart the agent so it picks up the new voice.
