Every file, document, dashboard, and image your agents create is collected in one place: the **Outputs** page. You can browse everything your hive has produced, filter by agent or file type, preview files in the browser, and download them to your local machine.

## Open the Outputs Page

You can reach Outputs in two ways:

- Click **Outputs** in the left sidebar to see everything across all agents and swarms.
- Open an individual agent or swarm and select the **Outputs** tab to see only that agent's deliverables.

## Browse and Filter

The Outputs page shows a grid or list of every deliverable. Use the controls at the top to narrow the view:

| Filter | What it does |
| --- | --- |
| **Search** | Find outputs by name or keyword. |
| **Sort** | Order by most recent or oldest first. |
| **Type** | Show only web apps, documents, spreadsheets, images, presentations, data files, or other types. |
| **Agent** | Filter to outputs from a specific agent or swarm, or view all agents at once. |

## Preview a File

Click any output to open a preview panel. What you can do depends on the file type:

- **Text and code files**: View the contents directly. You can copy the contents to your clipboard or switch to the raw source tab.
- **Spreadsheets**: See a formatted preview of the first rows. If the file is very large, only the beginning is shown.
- **Documents and presentations**: Kolmena converts them to PDF for preview when possible. If conversion fails, download the file to open it locally.
- **Images**: View the image inline at full resolution.
- **Dashboards**: Open the dashboard in a new tab to interact with filters and widgets.

<Tip>
  If a preview says the file is too large, use the **Download** button to get the full file.
</Tip>

## Download a File

Every output has a **Download** button in the preview panel. Click it to save the file to your computer. If the download fails, check your network connection and try again.

<Note>
  Some file types cannot be previewed in the browser. For those, the preview panel will prompt you to download the file and open it with a local application.
</Note>

## Archive and Restore

If an output is no longer relevant, you can archive it to clean up your view. Archived outputs are hidden by default but can be restored later. Look for the **Archive** action on an output card or in the preview panel, and use **Restore** to bring it back.

## Outputs from Marketplace Listings

If you installed an agent or swarm from the Marketplace, some of its outputs may be marked as creator-managed. These are kept up to date by the listing creator and cannot be edited or shared by you.
